SpeakPen 0.3.0 本机服务版

1. 覆盖安装 SpeakPen-0.3.0-debug.apk，直接开始对话，无需填写模型/API Key。
2. 电脑需保持开机联网。下次开机后双击“启动口语服务.cmd”。
3. 手机也可扫描“打开真实对话.html”的二维码，使用网页版或下载安装包。
4. 若临时地址变化，重新打开新入口，在手机页面点击“连接 App”即可更新。
5. 按住说话、松开发送、上滑取消。自己的原音频可重听；AI 使用千问云端语音，失败尝试系统朗读。
6. 已有聊天和复习库保留；旧版没有保存的原录音无法恢复。
7. 停止服务请运行“停止口语服务.cmd”。

阿里云 API Key 只在 server/.env。本机配对入口请勿公开分享。

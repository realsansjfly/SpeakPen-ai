# 独立官方百炼云端语音

SpeakPen 的聊天和语音识别继续使用现有兼容网关；AI 回复朗读单独调用阿里云百炼中国内地地域的 `qwen3-tts-flash`。两个 Key 相互独立，服务端不会把兼容网关 Key 发送到官方百炼地址，App 也不保存任何平台 Key。

## 一次性配置

1. 登录 [阿里云百炼 API Key 管理](https://bailian.console.aliyun.com/?apiKey=1#/api-key)，选择中国内地地域，创建或复制 API Key。不要使用 `maas.qianwenaiapi.com` 平台的 Key。
2. SSH 登录服务器，以 root 执行交互向导：

   ```bash
   bash /opt/speakpen/deploy/configure-official-voice.sh
   ```

3. 按提示粘贴官方 Key 并回车。输入不会显示，Key 不会出现在命令参数、Shell 历史或输出中。向导只更新 `/etc/speakpen/speakpen.env` 里的三个 TTS 字段，权限保持 `0600`，随后重启服务。以后只需更换 Key 时，也可以执行更短的 `bash /opt/speakpen/deploy/set-tts-key.sh`。
4. 打开 `https://47.118.51.5/health`。`speech:true` 表示独立朗读配置已加载；这不代表已经消耗额度做过真实合成。

现有 App 已请求 `/v1/audio/speech` 并播放返回的 WAV，因此服务器完成配置后无需重新打包 APK。若官方接口失败，App 会自动回退到 Android 系统 TTS；要区分二者，应在配置后发一条短消息并听音，同时检查服务日志。

2026-11-09 实装验收：`speech:true`，真实英文短句返回 HTTP 200 和 `audio/wav`；音频为 24 kHz、16-bit、单声道，规范化后标准解析时长 3.04 秒，服务日志无告警。

## 检查与撤销

查看服务状态和最近日志（不会输出 Key）：

```bash
systemctl is-active speakpen
journalctl -u speakpen -n 50 --no-pager
```

需要停用云端朗读时，删除 `/etc/speakpen/speakpen.env` 中 `DASHSCOPE_TTS_API_KEY` 的值并重启服务。不要把 Key 发到聊天、截图、Git 仓库或 APK 中。

# SpeakPen 0.6.0-dev02 · 设置与学习提示修复

发布日期：2026-10-26。开发预发布版本，包含本轮基础配置功能及首次体验反馈修复；APK 使用项目原有 Debug 签名。

## 更新内容

- **对话配置**：简单（A1–A2）、日常（B1）、深入（B2）三档难度，温度 0–1 与三档回复长度。每个会话保存独立配置，生成中的回复和历史消息保留原配置。
- **统一设置入口**：底部“偏好”改为“设置”，移除聊天页右上角按钮。在设置中切换“当前对话／新对话默认”；前者影响当前会话后续生成，后者只影响以后新建的会话。增加明确的保存、撤销、保存结果和未保存离开确认。
- **提示位置与折叠**：表达优化插入源用户文字块下方、回答块之前；话题语料继续追加到底部。两类提示均可折叠，旧优化提示按来源重新排列显示，保留原消息与数据。
- **双语话题语料**：每项要求英文表达、中文解释、英文例句和中文翻译。纯英文或纯中文结果会提示重试，失败不覆盖旧内容；没有增加自动收费重试。
- **数据与请求保护**：兼容旧数据，保留原录音、积累和配对设置；过期请求不能回写其他会话，服务端限制参数范围与预算。

话题语料提示词入口：Android [`LearningPrompts.topic()`](../../app/src/main/java/com/speakpen/app/network/LearningPrompts.kt)，浏览器 [`topicPrompts()`](../../server/public/learning.js)。实现及诊断详情见 [第一批调试记录](../DEBUG-FIRST-BATCH-2026-10-26.md)。

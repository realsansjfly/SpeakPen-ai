# SpeakPen 0.7.0

发布日期：2026-11-09
Android：`com.speakpen.app` / versionCode 20 / versionName `0.7.0`

## 本版更新

- 首页改为本地 CSS 3D 话题圆柱：支持拖动惯性、自动旋转、换一批、“随便！”随机选择、减少动效和可访问列表回退。确认话题后由 AI 按当前难度与词库主动发起英文首问。
- 场景练习改为全页选择与任务简报。六个预设场景可先查看完整示范对话，支持整段或逐句播放，再决定是否进入正式对话；自建场景使用分组全页编辑器。
- 默认词库换为用户整理的 Anki 四级 4,027 条、六级 1,652 条和雅思同义替换 376 条，保留多义、音标、双语例句、笔记与词典摘录。
- 新增可选语义增强：按当前回合或最近对话检索相关词汇，支持三档引入强度和 4／8／12 个候选；服务不可用时回退本地筛词，不阻断聊天。
- 话题语料改为独立设置面，固定最近完整的一轮对话，可选择用途、难度和数量；学习内容不进入正式聊天上下文。
- 修复首页话题横滑与导航抽屉手势冲突、首页恢复时误换批、词库加载阻塞首帧、云端 TTS 凭据边界与流式 WAV 兼容问题。

## 安装与服务

公开 APK 不包含任何服务地址、配对令牌或平台 API Key。已有设备可覆盖安装并保留本机数据；首次安装需要在“设置 → 服务连接 → 重新连接”粘贴自己的私密配对入口。

## 验证边界

- Android `assembleDebug`、210 项 JVM 测试和 lint 已通过。
- 首页与学习流程的 HTML 预览已在 360／390／430px 和 150% 字号下检查，控制台错误为 0。
- 公开 APK 使用原项目 Debug 签名构建；未在本轮连接 Android 真机验证录音、播放、抽屉手势和覆盖安装。
- 云端真实聊天、SSE 和语音转写曾在私有部署上验证；公开 APK 不绑定该私有服务。

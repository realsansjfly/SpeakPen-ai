# SpeakPen 0.7.1

发布日期：2026-11-09
Android：`com.speakpen.app` / versionCode 21 / versionName `0.7.1`

## 修复

0.7.0 发布时误用了未配对构建，组员首次安装后没有云服务连接配置。0.7.1 使用固定云端构建，预置已部署的 HTTPS 云服务地址与应用访问令牌，打开后无需手动配对；历史本机／隧道配置不会覆盖固定云连接。功能沿用 0.7.0。

## 安装

下载 `SpeakPen-0.7.1-debug.apk`。已安装 0.7.0 或原项目同签名开发版的设备，直接覆盖更新即可保留本机对话、录音和词库，不需要先卸载。首次使用请保持联网，并在录音时授予麦克风权限。云服务不依赖维护者的电脑开机。

安装包包含应用连接云服务所需的访问凭据，下载者可调用该服务并产生模型费用；模型平台 API Key 保留在服务器，不进入 APK、展示页或源码。连接配置源文件 `.local/cloud-connection.json` 不提交到 Git。

## 构建与核验

```powershell
.\scripts\build.ps1 -JavaHome 'C:\EmojiJdk17' -Offline -Cloud `
  -OutputDirectory '.\deliverables\release-0.7.1'
```

使用 `-Cloud`，不要为组员发布使用 `-Unpaired` 的构建。附件 `SHA256SUMS.txt` 可核对 APK 完整性。

构建完成后，使用输出中的 ASCII 构建目录核验 APK，只有固定云配置、包名／版本、与源码一致性、原签名、JVM 测试及 lint 均通过才上传。核验脚本不输出访问凭据：

```powershell
python scripts/verify-cloud-release.py '<构建输出中的 ASCII 目录>' `
  'deliverables/release-0.7.1/SpeakPen-0.7.1-debug.apk' `
  --previous 'deliverables/release-0.7.0/SpeakPen-0.7.0-debug.apk'
```

## 已接入 Android

- `MainActivity.kt` 移除底栏，使用 `Navigation.kt` 中的 Material 3 左侧导航抽屉，宽度约 75%。抽屉展示真实应用图标、本机身份、积累库、按今天／昨天／更早分组的历史及底部设置；没有伪造账号、统计或云同步。
- 聊天顶部只保留抽屉、自由聊天／场景互斥选择、新建对话。原有收藏练习从积累库进入；历史中的收藏练习仍可恢复。
- 设置是独立页面，列表按对话范围、显示播放、服务连接和体验模式分组。返回时先保存，失败留页显示重试；切后台也尝试保存。草稿包含当前／默认两组编辑，恢复草稿不复制配对凭据。
- `SettingsNavigation` 统一离开和保存结果状态；`SettingsEditorDraft` 提供本地恢复。恢复只关联原会话 ID，不能把会话参数应用到其他历史。
- `ChatSession.draft` 保存每个会话的未发送文字；新建与恢复会话保留草稿，400ms 防抖写入、退后台补写。旧数据缺字段时按空草稿读取，原消息、录音路径及场景数据继续兼容。
- 首页从本地候选池随机排列三行话题，点击填入输入框后再由用户发送。没有话题说明或暂停行，也没有为推荐话题调用模型。窄高空间会减少显示行数；启用读屏或关闭系统动画时静态展示。
- 动效在输入、录音、抽屉、其他页面或后台停止；触摸或焦点进入话题时暂停所在行。模式选中背景滑动，页面短距进出，目标和高级设置平滑展开。
- 场景摘要默认收起新练习目标，已有折叠状态保持；结束后隐藏输入区，保留自由续聊。离开页面／切模式不结束旧场景。开场白等待、取消和失败重试入口可达。
- 用户绿气泡、AI 白气泡、蓝色辅助提示与 Nunito 字体沿用原主题；表达优化位置、语料位置、持久折叠和提示隔离继续沿用原业务。

## 安装与待验收

使用本轮 APK 覆盖安装，保留现有记录、录音和配对；不要求卸载。全新安装是未配对状态，服务入口位于“左侧抽屉 → 设置 → 服务连接”。没有嵌入现用配对地址或令牌。

本轮 `adb devices -l` 无设备，SDK 中未发现可用模拟器与系统镜像；没有进行设备安装或截图。仍需设备验收：

1. 覆盖升级后旧记录、录音、积累与场景结束边界；抽屉左右滑动、遮罩与系统返回，长历史滚动。
2. 当前／默认配置各自修改后返回保存；断电／磁盘失败、强杀重启、后台保存和配对变化期间的草稿恢复。JVM 测试验证状态与编解码，不等于设备文件系统异常注入。
3. 小屏、大字体、横屏、输入法 Insets、TalkBack 和系统关闭动画后的布局与行为。
4. 真实麦克风按住／松开／上滑取消、中文求助、原音回听，以及联网 AI 消息和错误恢复。
5. 话题流实际帧率、触摸选择、动画观感与耗电；场景目标展开、依据、更正和只读续聊。

聊天草稿采用防抖写入，系统在输入后 400ms 内直接杀进程仍可能来不及保存最新字符；正常页面切换和退后台会补写。设置草稿通过独立恢复记录保护，未宣称已完成所有设备存储异常验收。

设置写入涉及偏好与学习数据两个存储，采用顺序保存，失败保留页面及重试，不能宣称新的跨文件原子事务；失败前可能已有部分写入。强杀恢复、配对变化及实际磁盘故障的完整设备行为仍待验证。

# SpeakPen Android v0.1 实施计划

目标：先验证英语口语练习的软件闭环，后续复用核心操作接入笔形硬件。

## 本次交付

- 原生 Android：Kotlin、Compose，Android 8.0 及以上。
- 三页：对话、复习库、设置；奶油纸色、深绿、琥珀点缀，清晰显示状态。
- 可配置兼容 Chat Completions 的 Base URL / API Key / 模型 ID，实际发送小请求测试连接。
- 自由对话、复习对话。复习可选择词汇 / 表达 / 话题，AI 按目标展开提问，逐步引导，不一次灌输。
- 英文输入 / 中文求助切换，文字可编辑、消息可标记卡壳，重说上一轮。
- 系统 SpeechRecognizer 和云端 multipart `/audio/transcriptions`；英语默认 en-US / en，中文求助 zh-CN / zh，录音不会未经用户点击自动上传。
- 录音结束后先转写到草稿，再编辑并发送；网络失败保留云端录音供重试，取消可丢弃。
- 设备 TTS 朗读 AI 英文，手动播放 / 停止，可开启自动朗读。
- 用户主动点击 AI 总结：读取当前对话、中文求助、用户卡壳标记，返回结构化候选；预览、编辑、勾选后入库。
- AI 不能仅凭转写恢复真实停顿；未标记的候选只标为推测，不当作诊断。
- 复习库手动增删改、搜索、选择目标、掌握 / 再练及下次日期。
- 设置、对话历史、复习库本地持久化；API Key 使用 Android Keystore 加密，禁止应用备份。
- 明确标识的演示模式，不调用远程模型。

## 第一版边界

分段语音，不做 WebSocket 全双工实时语音。只支持兼容聊天接口和兼容转写接口；不是所有服务商协议都相同。语音准确率需要真机、不同口音和环境测试，不做百分比承诺。

先用纯文字与 mock 服务测试请求、响应、结构化候选和失败恢复；完成 Debug APK、单元测试与 lint。真机测试步骤单独记录；没有连接手机时不声称已经验收麦克风或音频。

## 后续

流式回复与中断；词汇复习算法与长期反馈；导出 / 云同步；蓝牙硬件按钮；私有服务端和账户体系；provider 原生协议适配。

## 0.2.0 范围更新 · 2026-10-13

- 用户不再配置模型：采用运营后端固定模型，聊天流式返回，凭据不进 APK。
- 支持 Groq / SiliconFlow 两条正式 API，部署地区与限流需实际核验。
- 语音改为按住录音、松开发送、上滑取消，原音频与时长持久保存。
- 统一本地录音 + 服务端转写，停止依赖系统识别路径；AI 使用设备 TTS 朗读。
- 白底与绿色语音气泡、蓝色辅助色、圆角卡片，保留简单学习操作。
- 真实服务开通还依赖运营 Key 和 HTTPS 地址。当前交付如未设置地址，明确显示准备中；示例体验由用户主动选择。

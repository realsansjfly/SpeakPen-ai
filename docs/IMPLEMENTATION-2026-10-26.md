## 第 1 批实际改动

- 聊天页增加“当前对话设置”；偏好页增加“新对话默认设置”。打开配置界面不创建新会话。可将当前配置设为新对话默认；修改默认不会回写历史会话。
- 简单／日常／深入分别采用 A1–A2／B1／B2 表达目标。主回复、表达优化、话题语料和单条提取均读取配置，保留中文求助与既有复习目标。难度不改变录音或播放速度，不包含自动测评／升降档。
- 对话高级设置提供温度 0–1（默认 0.7）和简短／适中／较充分回复。后端分别映射到 120／240／400 token 上限；不允许客户端任意扩大预算或切换运营模型。长度是目标和上限，不保证每次回答都填满。
- 恢复默认只恢复高级参数，不改难度、消息、收藏或音频。复盘／抽取相关的旧 summary 和 learning 任务保留独立预算，不继承对话温度／长度。
- 会话保存配置及递增版本，生成消息／蓝色提示保存发起时配置。修改配置仅影响新生成；重生成沿用选中块原配置，旧版无配置消息使用日常默认。原话、后续消息及提示隔离逻辑保留。
- 流式增量和完成结果校验请求代次、会话 ID、消息 ID／修订／文本。取消后清除流式草稿，保留原录音；被取消的转写转为可重试状态，过期回包不能写回。
- 默认主回复要求不主动纠错；本批没有提供实时纠错开关。手动优化与中文求助不受此约束禁用。
- 新服务在带鉴权的 status 中声明高级参数能力；旧服务仍可聊天，但高级控件提示服务需更新并禁用。避免新 App 连接旧进程时静默忽略所选参数。
- 数据格式增加到版本 2，新字段有旧数据默认值，沿用 learning.json、SharedPreferences 和 AtomicFile。没有引入数据库迁移或删除既有字段。
- 开发包为 `com.speakpen.app` / `0.6.0-dev01` / versionCode `8`，高于已分发的组员体验包 `7`。构建脚本增加独立输出路径与不嵌入配对信息选项，保留 Windows 中文路径镜像和 Java Selector 回退。

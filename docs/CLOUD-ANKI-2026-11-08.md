## 云服务

`deploy/` 提供适用 Ubuntu 24.04 的 Node 22／Nginx／systemd 安装、隐藏输入百炼 Key、Certbot HTTPS 配置。以独立系统用户运行，Node 仅监听 127.0.0.1:8787；Nginx 暴露 80／443。应用服务令牌随机生成，云模式缺失有效令牌拒绝启动。额度文件保存至 `/var/lib/speakpen/usage.json`。

`scripts/package-cloud.ps1` 通过白名单打包服务、四个网页运行文件、脚本和文档。排除 `.env`、`.local`、APKG、APK 及本地密钥。安装脚本和配置文件作为原文提供，可先检查再执行。2 核 2G 不在服务器运行大模型或 Android 构建。

`scripts/configure-cloud-app.ps1` 将 HTTPS `/v1` 地址和独立应用服务令牌保存到忽略目录；`scripts/build.ps1 -Cloud` 构建云端直连版本。云模式隐藏“服务连接”模块，忽略外部配对链接，并优先使用构建地址，防止旧隧道设置抢先。普通开发／未配对构建保留原流程。提供测试输入接口的 JVM 测试检查该升级规则。

正式云地址、域名备案／DNS、证书及服务器令牌尚未确定；未实际登录 ECS、安装软件或调用云上服务。浏览器仍使用完整的服务入口链接配对。服务器部署过程、预期输出和排障见 [逐步教程](CLOUD-DEPLOYMENT.md)。

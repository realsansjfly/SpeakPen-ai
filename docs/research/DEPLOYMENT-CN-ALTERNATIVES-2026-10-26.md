# SpeakPen 国内替代部署与大陆网络：有界调研

调研日期：2026-10-26。对象：中国大陆 Android 用户；香港仅作对比。

## 结论给主代理

- **尽量少改现有 Node 服务和文件额度账本：优先评估阿里云中国内地轻量应用服务器。**它面向小型 Web/APP 后端，支持自选系统或容器环境；把服务从 PC 搬到云主机即可解除 PC 持续在线依赖。需自行管理进程、HTTPS、更新、备份、磁盘和并发写入；不是免运维或自动高可用。[S11][S12][S13]
- **希望按需缩容、少管服务器：FC Web 函数是可行候选，而不是普通事件函数直接替换。**官方明确支持 SSE；同步 HTTP 请求体上限 **32 MB**，覆盖项目最多 **6 MB** 音频这一输入要求，但仍须检查实际编码后大小。创建 Web 函数的执行超时默认 **60 秒**、最大 **86400 秒**，不代表整条客户端/代理/SSE 链路保证同样时长。[S1][S2][S3][S4]
- **FC 最重要的迁移阻碍不是 fetch，而是持久化额度。**实例本地磁盘随回收删除；NAS/OSS 可持久化，但 OSS 挂载不具备等同本地文件系统的语义，不同实例之间也可能不能实时看见新文件。不能把当前文件额度账本未经并发设计直接放到 FC 本地或 OSS 挂载上。[S3][S8]
- **FC 不能简单宣传“几乎免费”或“只算 CPU 执行”。**现行官网以 CU 加公网出流量计费；符合条件的函数存在**每小时 0.01 元最低消费**。SSE 等待上游期间仍在处理请求，资源规格和占用时长相关成本不能忽略。最小实例数大于零会持续收费。[S5][S6]
- **纠正可能过时的结论：Cloudflare China Network 当前官方功能表已列出 Workers。**但必须是 **Enterprise + 单独 China Network 订阅**，域名需有效 ICP 备案/许可并通过京东云内容审核；不是普通 Workers 自定义域名自动进入大陆节点。[S15][S16][S17]
- **普通 Workers 的大陆“稳定直连”没有在本轮得到官方保证。**官方说明境外节点路径面临明显延迟与可靠性问题；没有找到能证明所有大陆网络下普通 `workers.dev` 一律被封、或自定义域名一定可用的官方规范性材料。两种绝对判断都不应写成事实。[S15][S18]

## 研究边界与证据口径

项目条件由任务给定，未重新审计代码：Android 上传最多 6 MB 音频；Node 22、无 npm 运行时依赖；以 fetch 调用阿里云 DashScope 聊天/ASR/TTS；输出 SSE；额度写入文件。

仅研究 FC、轻量应用服务器，以及 Cloudflare 中国网络与普通 Workers 的大陆网络边界。**未搜索 Workers 通用价格、通用运行时或 Containers**；未开账号、部署、付费调用模型或实测大陆运营商链路。

按 research 的“原始来源、单份文档、逐项引用”原则执行；读取 agent-reach 后，按用户指定使用 **anysearch MCP 搜索及 extract**，不改用其他搜索后端。当前工具未提供可用子代理派发接口，因此在本调研上下文完成，未另建用户聊天冒充后台子代理。

以下“官方事实”来自供应商产品文档或政府公开文件；“工程判断”是针对项目条件的推导，不代表厂商承诺。搜索摘要日期不作为发布证明；不采用晚于调研日的事件。Cloudflare 所引用文档正文标示更新于 2026 年 4 月或 6 月，早于本次截止日。阿里云提取正文通常不显示更新时间，因此只能说明本次读到的页面内容，不能据搜索日期重建历史版本。

## 一、阿里云函数计算 FC

### HTTP、SSE、上传与超时

| 项目 | 官方事实 | 对 SpeakPen 的含义／边界 |
|---|---|---|
| Web 服务形态 | 自定义运行时托管用户 HTTP Server；通过 HTTP 触发器或自定义域名调用时透传 HTTP 请求、响应，部分保留字段除外。[S2] | 可继续使用 Node HTTP Server；无须仅为接入模型引入 SDK，但仍要核对监听地址、端口、启动方式。 |
| SSE | Web 函数支持流式响应，事件函数、任务函数暂不支持；依据 `Transfer-Encoding: chunked` 识别流式输出。[S1] | 应选择 Web 函数形态，保留 `text/event-stream`、分块输出及及时 flush；部署验收必须检查是否真实逐块到达。 |
| 请求体 | 同步请求 Body 上限 32 MB；异步请求默认上限 128 KB，配额页说明可申请调整至 256 KB。[S2][S4] | 6 MB 音频适合直接同步 HTTP 上传；不能把同一音频直接塞进异步事件。若使用 base64/JSON，必须按实际请求体而非源文件大小验收。 |
| 执行时限 | 创建 Web 函数页面写明默认 60 秒、最大 86400 秒；配额页也列出函数最大运行时间 86400 秒。[S3][S4] | 默认值可能不足以覆盖慢速上传、ASR、聊天、TTS 串联，需显式配置合理时限，而非直接采用最大值。 |
| HTTP 默认域名 | 内置域名仅用于测试，不应作为线上对外服务入口；默认域名响应强制添加附件下载头。[S2] | Android API 客户端与浏览器行为不同，但这不能推翻官方“测试用途”限制，生产宜用自定义 HTTPS 域名。 |

**未核实项：**本轮未找到适用于这条具体 FC HTTP/SSE 路径、独立于函数执行时限的统一“首字节/连接空闲超时”官方数值。因此不能把函数最大运行时间说成 SSE 保证在线时长，也不采用社区所说的其他网关超时。若前面增加 API 网关、CDN 或反向代理，还须分别复核其流式支持、缓冲和超时。

### Node 22、应用中心与容器部署

**可确认的部署路径：**

1. **Web 函数 + 自定义运行时 + ZIP/文件夹/OSS 代码包。**官方支持设置启动命令和监听端口；特定语言版本可随代码打包。SpeakPen 可保持无 npm 运行时依赖，运行时二进制或部署工具不是业务 npm 依赖。[S3][S7]
2. **自定义镜像函数。**官方支持将自选运行环境装进镜像；文档要求同账号、同地域的 ACR 镜像仓库，构建平台采用 Linux/AMD64。对严格保留 Node 22 的目标，镜像通常更容易固定环境，但增加镜像构建、仓库、权限及冷启动工作；仍须选择/确认支持 HTTP 流式响应的 Web 服务调用形态，不可仅据“容器”二字断言 SSE 已接通。[S1][S9]
3. **Serverless 应用中心。**可用于应用生命周期管理和持续部署，官方 Web 快速入门也将它列为 CI/CD 路径。应用中心本身免费，模板创建的 FC、NAS、SLS 等底层资源可能收费；不是另一种“免费常驻主机”。[S19][S20]

**Node 22 限定：**本轮官方运行时总表的普通 Node.js 内置运行时最高列到 Node.js 20；另列有 Node.js 22 的 **MCP 专用运行时**。这不能证明普通 Web 函数有开箱即用的 Node 22 选项。应采用自带 Node 22 的自定义运行时或镜像，并以实际控制台可选项、Linux 兼容性验证为准；不建议为了借用版本而误选 MCP 专用环境。[S7][S21]

### 缩容与冷启动

- 官方 Web 教程说明请求到达时启动/扩展实例，无访问时自动销毁；按需模式可缩容到零。[S19]
- 最小实例数为零是默认计费场景；未调用且未持续占有资源时不产生该函数计算用量。配置延迟释放、会话亲和或其他关联资源时，不能推广为“整个账号无请求零费用”。[S5]
- 配置最小实例数大于零可以降低冷启动影响，但实例持续保留，无请求时仍有浅休眠等资源费用，也可能触发小时最低消费。扩容超出保留量的实例仍须考虑冷启动。[S5][S6]
- 官方最小实例数文档称 CPU 业务平均冷启动为百毫秒级、取决于应用启动；这不是 SpeakPen 或镜像拉取的保证。镜像文档明确提到下载和解压带来额外冷启动时间。[S6][S9]

**工程判断：**这是人机语音交互，冷启动影响首个响应体验，但不必因此一开始就购买常驻资源。应先用按需 Web 函数测量上传完成至 SSE 首包的延迟，再决定是否保留实例。

### 文件额度持久化：上线前的硬阻碍

官方明确指出函数磁盘与实例同生命周期，实例销毁后文件删除；持久数据应挂载 NAS 或 OSS。[S3][S8]

对当前额度账本，单纯“设置最小实例数”不是持久化方案：更新、故障、回收、扩容仍可能换实例。NAS/OSS 提供保存能力，也不自动提供跨实例额度扣减事务。

尤其是 OSS 挂载，官方说明：[S8]

- OSS 本身不支持文件系统 API；随机写等操作由下载、改写、重新上传模拟。
- 数据通常在 flush 或关闭文件时上传。
- 不同函数实例之间独立，某实例创建的文件可能无法被另一实例实时查询到。

**工程判断：**严肃额度应使用具备原子更新/条件写入/事务能力的共享存储方案，并处理重复请求；如果先用共享文件/NAS，仍需设计锁、崩溃一致性和并发扣减。不能仅换挂载路径后就声称安全。限定最大实例数或并发度可降低风险，不等于消除数据丢失或所有竞态。

**文档冲突：**[S3] 的磁盘示例含“提供 10GB 磁盘免费使用额度”，而 [S5]、[S22] 明确说明 512 MB 规格免费，并给出其他磁盘计量。故本报告不承诺“10 GB 永久免费磁盘”，报价时应复核实际规格和账单；临时磁盘容量更不等于额度持久化容量。

### 计费：采用中国站当前文档，不混用国际站美元价

官方现行计费结构：**CU 使用量 + 公网出流量**；公网出流量由 CDT 计费。CPU、内存、调用、磁盘等先按系数折算 CU。[S5]

| 官网项目 | 官方数值／说明 |
|---|---|
| 按地域独立累计的月 CU 阶梯 | `(0, 2亿]`：0.00011 元/CU；`(2亿, 10亿]`：0.00010 元/CU；超过 10 亿：0.00009 元/CU。 |
| CPU 业务活跃系数 | vCPU：1 CU/(vCPU·秒)；内存：0.15 CU/(GB·秒)；调用：75 CU/万次；磁盘：0.05 CU/(GB·秒)。512 MB 磁盘规格文档注明免费。 |
| CPU 浅休眠系数 | vCPU 为 0；内存仍为 0.15 CU/(GB·秒)；磁盘仍为 0.05 CU/(GB·秒)，须结合免费规格。 |
| 计量基础 | 使用配置规格乘时长，不是只按进程实际消耗的 CPU 百分比、实际占用内存字节计算。 |
| 出账与最低消费 | 出账周期 1 小时；周期内各函数 CU 向上取整。单小时调用次数大于零或持续占有计算资源的函数，折算金额不足 0.01 元时按 0.01 元计费。 |
| 公网出流量 | 包括函数向公网请求产生的出流量、返回客户端的响应流量、CDN 回源流量；归 CDT，不能只计算给 Android 回传的文本。 |

表内数字均出自 [S5]。**特别注意：同页“官网折扣单价”标注活动期 2024-08-27 至 2026-08-27，已早于本次 2026-10-26。不能将其 0.000088 元/CU 等折扣当作当前有效价。**本报告使用非活动标准价做口径说明，不保证具体账号结算折扣。

对于 fetch 转发模型请求，等待上游/SSE 尚未结束不意味着函数无请求；不能只按拼 JSON 的短暂 CPU 工作时间估费。音频转发至 DashScope 的出流量也应计入核算。DashScope 模型费、持久存储、日志、镜像仓库等相关资源需另算；本轮未核实 CDT 当前分地域单价、账号可用免费包与实际总月账单，不提供虚构月费。[S5]

### 域名、备案与香港对比

- 中国内地 FC 自定义域名：文档要求已在阿里云完成/接入**网站备案**的域名，配置同地域函数、CNAME，可开启 HTTPS。[S10]
- 中国香港及海外 FC：同页明确绑定自定义域名不需要上述备案。[S10]
- 该页说明单次购买 FC 资源包订单金额 **100 元及以上**可获得免费 ICP 备案服务码。这是备案服务码的产品条件，不是法律上的统一备案费用，也不是“必须付 100 元才能使用 FC”。[S10]
- **香港免上述域名备案，不等于 APP 备案、经营许可、内容和数据义务全部豁免。**详见下文备案边界。

## 二、阿里云轻量应用服务器

### 适用性与最小迁移

官方把轻量服务器定位于小型 Web、APP 后端、开发测试等轻负载场景，也提供 Docker 方案。它把计算、存储、网络打包，仅支持包年包月；不需要 PC 一直开着。[S11][S12][S13]

**针对 SpeakPen 的工程判断：**模型推理在 DashScope，不需在轻量服务器购买本地推理/GPU；保留 Node 22 进程及现有 HTTP/SSE 接口，迁移量通常小于 FC 持久化改造。可以使用系统服务守护 Node 进程或容器重启策略；进程守护、TLS、SSE 代理缓冲/超时、请求体限制、密钥保护、限流和日志均需自己配置与验收。

额度文件可以落到主机持久磁盘，语义更接近现有设计，但仍必须迁移并备份数据、保护写入原子性，不要在磁盘尚未正确挂载时启用额度服务。未来增加多进程或多机时，也要重新设计共享额度。[S12][S13]

代价是持续包年包月成本和自行运维；单台主机不是自动故障切换架构。到期/欠费会停服，未及时续费还可能释放实例与快照，不能将“云端运行”当成“永久不会中断”。[S13]

### 价格应如何报告

| 成本项 | 官方口径 |
|---|---|
| 基础套餐 | 计算、存储、网络打包，包年包月。详细套餐金额以产品购买页为准。[S12][S13] |
| 额外数据盘 | 可选，按盘规格、容量、地域和购买时长计费。[S12] |
| 流量 | 标记“无固定流量”的套餐不收超额流量费；上一代含固定月流量的套餐超过后按量计费。[S12] |
| 超额流量例示单价 | 文档列中国内地 0.8 元/GB、中国香港 1 元/GB；流量指**出网**，入网不计费。该页同时声明价格仅为示例、以购买页为准，不能脱离套餐套用。[S12] |
| 域名、DNS、证书等 | 可能另收费；官方也列出免费版 DNS、免费试用 DV 证书等选项。不要把附加付费服务当成运行 Node 的强制条件。[S13] |

**无法核实的报价：**本轮官方产品页提取的套餐卡片显示“询价中”，未取得可核对地域、CPU/内存、磁盘、线路、流量、期限、新老用户资格及续费价的当前完整报价。因此不宣称内地或香港固定“每月多少元”。产品页虽然显示其他应用活动“低至 68 元 1 年”，不能据此证明 SpeakPen 所需配置的常规/续费价格。[S11]

官方计费文档中的“杭州 34 元/月”等属于**计费示例而非有效报价**，且复杂示例存在混杂币种和公式，不适合作采购依据。[S12] 主代理若需要数字预算，应另取实际购买页报价并记录：

> 地域、套餐/线路、CPU/内存、磁盘、公网峰值带宽、固定流量或无固定流量、首次购买总价、期限、资格限制、原价/续费价、附加资源、报价日期。

### 大陆与香港网络

官方地域文档明确警告：香港及海外与中国内地网络非直连，大陆访问可能延迟、丢包，甚至无法访问；这些地区提供的带宽主要面向非中国内地用户，不建议内地用户直接采用。不能因为“香港地理近、免域名备案”就推断体验等同大陆。[S14]

另一个重要限制是：轻量套餐公网带宽属于**出、入方向峰值上限，不是承诺指标**；高峰争抢时可能限速、丢包。即使页面显示高峰值带宽，也不能把它当作音频上传或 SSE 可用性保证。[S12][S14]

**选择建议：**主要用户在大陆时，先评估靠近用户的内地地域；香港保留为对照/测试候选，须分别测试客户端到服务和服务到 DashScope 的连接，不给出未经实测的毫秒延迟结论。

## 三、Cloudflare：China Network 与普通 Workers 要分开

### 已确认的 China Network 条件

官方概述称 China Network 是在大陆数据中心运行选定产品、由京东云运营的网络；对 Enterprise 客户以单独订阅提供，根域名必须持有效 ICP 备案或许可。[S15]

接入文档要求：Enterprise、追加 China Network 包、同意补充条款、提供 ICP 信息、京东云审查域名内容后接入。即使试点 PoC 也需要 ICP 与内容审核，不是绕过备案的免费试用通道。[S16][S18]

截至本轮读取的 **2026-06-10 更新**功能表，Developer Services 中明确列出 **Workers**，以及 KV、静态 Assets、Secrets、Service bindings 等。**因此“Cloudflare 中国网络完全不支持 Workers”是过时或至少不符合本次官方文档的说法。**但功能清单不证明每个全球 Worker 依赖都能无差别迁移，需按该业务实际绑定/能力向官方确认。[S17]

本轮没有查询其 Workers 通用运行时、价格或 Containers，也未取得 China Network 面向该项目的合同报价；不提供价格猜测或开通承诺。

### 普通 Workers：官方证据支持什么、不支持什么

官方概述直接说明：要快速、可靠地向大陆交付内容，需要大陆基础设施；流量经过境外服务器会因网络边界出现显著延迟与可靠性问题。[S15]

可以据此写：

> 普通全球 Workers 与单独购买并接入的 China Network 不是同一项大陆可用性承诺；不能仅更换自定义域名就认定获得大陆节点和稳定直连。面向大陆用户应进行实际网络验收，准备替代部署。

本轮**不能**据此写：

- “所有普通 Workers 在大陆都无法访问”；
- “`workers.dev` 全国所有运营商永久被封”；
- “换成自己的域名就能保证大陆可用”；
- “买普通 Workers 付费计划就包含 China Network”；
- “只要 China Network 支持 Workers，就可不备案部署到大陆”。

搜索命中 Cloudflare Community 的 `workers.dev` 访问讨论，但社区域名上的用户回答不是服务官方保证，也不是本轮可用性实测，未作为结论证据。没有查到覆盖所有普通 Workers/域名/运营商组合的官方通断清单或大陆访问 SLA。

## 四、域名备案与 APP 备案：不可互相代替

**域名/网站侧：**上文 FC、轻量服务器要求描述的是相应云服务绑定域名或在内地对外提供服务时的产品接入条件；香港/海外的域名备案例外仅在这个层面引用。[S10][S14]

**APP 侧：**工信部《关于开展移动互联网应用程序备案工作的通知》（工信部信管〔2023〕105 号，湖南省政府转发全文）规定，在境内从事互联网信息服务的 APP 主办者应履行备案手续；已做网站备案的仍需补充 APP 信息。阿里云 APP 指引也要求 APP 包名、公钥、签名等特征信息，显然不是仅绑定后端域名即可完成。[S23][S24]

因此：

- 网站域名完成备案 **不等于** Android APP 自动完成备案。
- 云主机放香港 **不自动等于** 面向大陆提供 APP 服务可以免 APP 备案。
- 个人自用、测试安装与正式公开提供服务的适用情况，需要依据具体主体、功能、分发方式向接入商、分发平台及属地主管部门核实；本轮不作一刀切判断。
- 本项目涉及语音数据和 AI 服务；本报告不评价其是否还涉及其他许可、数据合规、内容管理或生成式 AI 服务义务，也不提供泛化法律合规保证。

## 五、给主代理的决策与后续验收清单

| 候选 | 适合当前目标的点 | 不可忽略的阻碍 | 建议定位（工程判断） |
|---|---|---|---|
| 内地轻量服务器 | 保留 Node 服务和文件持久化，解除 PC 在线依赖，月/年套餐较可预测 | 自行运维、备案、文件写入与备份、带宽非承诺 | **最小迁移优先候选** |
| 内地 FC Web 函数 | 官方支持 HTTP/SSE、按需伸缩、免管服务器 | 持久化额度与跨实例一致性；冷启动；小时最低消费；自定义运行环境 | **愿意改持久化后再优先考虑** |
| 香港轻量／FC | 可比较不同接入流程，无上述内地自定义域名备案条件 | 大陆跨境链路风险；不能据此豁免 APP 等义务 | 对照或特定场景候选，不默认面向大陆最优 |
| 普通全球 Workers | 此处不评价其通用开发或价格优势 | 大陆稳定可达性未获官方保证；不自动含 China Network | 不以“大陆稳定”作为推荐理由 |
| China Network Workers | 官方列为大陆网络支持能力 | Enterprise + 独立订阅 + ICP + 内容审核，报价未核实 | 企业级路线，不默认个人项目低门槛替代 |

后续仅供主代理规划，本轮未执行：

- 确认最终公网入口、域名与备案类型；不要把测试域名直接固化为生产地址。
- 真机按最大音频请求体测试上传、ASR、聊天首包、SSE 分段、TTS 下载、断网和取消。
- 测试上游慢响应、代理缓冲和连接空闲；不要只测最终 HTTP 200。
- 验证重启/回收/重新部署后额度不丢失；并发和重试不重复扣费、不超发。
- 测试大陆实际用户网络及高峰时段；香港与全球 Workers 不用一次成功代表长期稳定。
- 取得实际套餐/实例报价，联算 DashScope、出流量、持久存储、日志；保留证据日期与续费价。

# 0.6.0-dev02 — 2026-10-26（预发布）

- 新增简单（A1–A2）、日常（B1）、深入（B2）三档表达难度；每个对话保存独立配置，新对话继承默认值。
- 新增温度及回复长度控制，服务端限制允许的参数和预算；生成消息保留配置快照，取消或切换对话后忽略过期结果。
- 底部“偏好”改为“设置”，移除聊天页右上角设置按钮；在同一页明确区分“当前对话”和“新对话默认”，增加草稿、保存／撤销、成功／失败反馈及未保存离开确认。
- 表达优化显示在对应用户消息下方、AI 回复之前；话题语料仍放在底部。两类提示均支持折叠并保存折叠状态，兼容旧提示位置。
- 话题语料要求逐项提供英文表达、中文解释、英文例句和中文翻译；Android 与浏览器同步提示词，拒绝纯英文或纯中文结果，生成失败保留原内容。
- Android 102 项单测、lint 0 问题；Node 46 项测试通过；3 组真实模型话题样例通过。新增界面、滚动、覆盖升级和存储异常尚待真机验收。
- 公开包为 `com.speakpen.app` / versionCode 9，与原 0.4.0、dev01 同签名；不内置服务配对凭据。六字段场景、词库导入、分层提示及新复盘／统计仍待后续批次。

下载与安装：[v0.6.0-dev02 Release](https://github.com/realsansjfly/SpeakPen-ai/releases/tag/v0.6.0-dev02)；[完整版本说明](releases/v0.6.0-dev02.md)。

# 0.1.1 — 2026-10-12

- 修复系统录音停止后仍显示正在录音的问题。新增“正在识别”状态与进度提示，停止操作幂等，等待期间可取消。
- 系统识别超过 8 秒没有最终结果时，保留最近的部分识别文本供检查；没有文本则明确提示超时。完成或取消后释放识别服务；忽略晚到的结果。
- 修复连续新建对话产生多条 0 消息记录。未发送消息的当前会话复用，模式与复习目标可更新；历史只显示有消息的会话。
- 启动时清理旧的空历史，保留当前空会话、真实对话和复习库。相同应用 ID 和调试签名，版本号递增，可覆盖安装。
- 新增 12 项回归测试；先在原行为上复现，再验证修复。

# 0.2.0 — 2026-10-13

- UI 重做：白底、浅绿色语音块、蓝色辅助色、圆角卡片，聊天 / 复习 / 偏好三页。Nunito 字体本地打包。
- 删除用户模型配置页面。模型选择、额度、密钥和备用线路由新 Node 服务管理。
- 默认接入 Groq GPT-OSS 20B + Whisper Turbo；可只配置国内 SiliconFlow Qwen3-8B + SenseVoice。
- SSE 流式显示短英文回复；设备 TTS 朗读，回复可按偏好显示语音块或原文，也可逐条展开。
- 按住录音、松开发送、上滑取消；发送时保存原录音与真实时长，支持重听和重启恢复。
- 转写失败保留语音块，可重试或手动补充文字；转写/聊天中断不删除原音频。
- 旧版 API 配置不再使用；偏好保存会替换旧配置。保留旧对话和复习库，旧版未保存的原音频无法补回。
- 默认真实模式；服务地址尚未配置的构建明确展示待开通，可主动开启示例体验。没有声称在缺少运营凭据时已接通真实 AI。
- 新增可交互 HTML 设计预览，明确标识为预览；浏览器交互检查不等同于 Android 真机验收。

# 0.3.0 — 2026-10-15

- 阿里云凭据接入本机 .env，真实验证 Qwen3.7-Flash 聊天、Qwen3-ASR-Flash、Qwen3-TTS-Flash。
- 修正 ASR 协议：阿里云使用 chat/completions 的 input_audio data URL，服务端向 App 归一化为 {text}，无需手机变更转写协议。
- 云端朗读与本机缓存；旧的系统 TTS 作为故障备用，不再要求所有手机预先安装英文语音包。
- 手机安装包预置本机服务地址和独立配对令牌，阿里云密钥只留服务端。
- 启动时退出旧版示例模式，提供服务连接检查和 speakpen:// 配对更新入口。
- HTTPS 临时连接、二维码入口、启动/停止脚本。电脑重启后可重建连接并更新 App，不必重填模型。
- 后台每日额度持久化、鉴权、音频下载域名校验、TTS 缓存、APK 授权下载。
- 新增真实可用的浏览器对话入口，支持原录音保存、转写、中文求助、收藏与目标复习。
- Quick tunnel 路径用 JSON 短回复；稳定部署仍可开启 SSE，不宣称零延迟。

# 0.4.0 — 2026-10-19

- “收藏好表达”改为打开空白、可编辑的积累条目，不再默认整理全场对话，不产生模型请求。
- 长按 AI 对话块：识别好表达、复制、重新生成。识别只提交选中块，候选可编辑/勾选，确认后入库。
- 长按自己的对话块：识别好表达、复制、优化表达；语音尚无转写时提示先完成转写/补充文字。
- 优化表达生成蓝色“提示 · 优化表达”块，保留原话，不更改事实和意图；提示不作为 user/assistant 进入上下文。
- 新增下方“话题语料”，按当前真实对话生成短语/搭配、中文释义和例句，显示蓝色“提示 · 话题语料”。
- 提示块同样支持长按识别、复制、重新生成；重新生成使用原锚定的来源/上下文，不引用后来的对话。
- 重新生成只替换所选块，保留其 ID 和后续对话；音频缓存按 revision 区分，避免重听旧回答。
- 普通聊天、重试、复习和整场摘要的历史过滤提示；等待回复判断也排除提示，避免插入提示后把待回复用户消息漏掉。
- 提示类型、来源消息、上下文锚点和修订号本地持久化，兼容旧数据。网页版同步以上流程。
- 新增 5 个开放英语资料候选与许可/用途核查清单，尚未导入，等待用户审阅。

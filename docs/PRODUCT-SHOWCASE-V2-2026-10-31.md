# 功能展示页第二版

原网址：<https://realsansjfly.github.io/SpeakPen-ai/>。

用户要求更清楚的分块、无交互的浮动话题展示、更多模拟界面和滚动出现动效。本轮调整展示页，不更改 Android／Node 真实练习逻辑、版本、现用配置或历史 Release。

## 变化

- 自由聊天、表达辅助、场景练习、词库增强、积累复盘采用独立底色和容器，章节在手机上纵向排列。
- 新增可横滑的 sticky 章节导航、当前位置下划线、顶部阅读进度、下滑入口和回到顶部，保持原生滚动。
- “今天，想聊点什么”变为三行连续漂移的中英文话题示意，移除换批按钮及话题点击，不调用模型。
- 八个 HTML 模拟画面包括首屏对话、空白话题页、分层提示、独立重说、场景目标、词库、积累卡和复盘文档。模拟图直接用 HTML／CSS 实现，清晰适配不同尺寸；截图交付仅用于验收，不冒充真机截图。
- 模拟图滚动进入使用不同的局部遮罩、轻移和角度变化；页面默认可见，脚本失败不隐藏内容。背景和话题流在离屏／后台时停止，提供暂停／播放按钮，系统减少动态效果时静态。
- 保留六场景切换、键盘分层提示、七组完整功能和边界说明、真实 APK 和版本记录链接。没有新增收费请求、录音或第三方资源。

## 验证与限制

Edge Playwright 检查 320、360、390、430、768、1440 宽度无横向溢出。话题无交互、三行运动、暂停恢复、离屏停止、动态切换系统减少动效、章节跳转和高亮、键盘提示展开、六场景切换、详情和下载地址、离线字体与交互、无脚本内容全部通过。`browser-verification.json` 记录本轮结果。

已目视检查手机和桌面整页、话题、复盘及首屏裁切。Impeccable detector 提示的重复图标已移除、示意说明已调大；详情列表间距由 summary 内边距承担，连续话题动效为用户明确指定并有暂停路径。不把这些修正写成自动扫描零告警。

公网页面仍使用独立 `codex/product-showcase-pages` 分支，只更新静态成品，保持 main 和已发布 App 不变。公网核验见 `hosting-verification.json`。真实手机、Safari、微信内置浏览器、设备帧率和功耗未实测。

# 第 4、5 批：学习辅助与复盘

实施日期：2026-10-31。Android 本地版本 **0.6.0-dev05／versionCode 12**，包名 `com.speakpen.app`。基线 main／4e70541，保留场景、dev03、dev04 的全部工作区改动；未提交、推送或发布。

## 第 4 批

- 表达提示使用一份结构化结果，按关键词 → 句子骨架 → 完整参考表达逐层揭示；初始只显示关键词。揭示不再发起接口调用。绑定上下文消息 ID、文本／修订摘要和发起时配置，后续正式对话或原句变化后禁止继续揭示旧提示，提示历史仍保留。可持久折叠、长按复制已揭示内容及重生成。
- 表达优化返回独立英文参考句与中文说明，仍位于原用户消息下方、AI 回答前。重说练习保存原句、优化消息 ID／修订、参考句、配置、录音与转写；练习不进入正式对话或复盘来源。重录保留每次录音，更多操作中的“练习录音”可回看。只有点击“发送到对话”才原子追加用户消息并标记已发送；每段只发送一次。原有回退重说移到更多菜单。
- 实时纠错默认关闭，作为会话配置／新对话默认的独立字段。主回复完成后发起独立 `learning` 请求，不阻塞主回复流式输出或场景判定；至多两项明确纠错，无错误返回空列表。只接受能匹配原用户文字的引用，显示为独立蓝色提示，不自动朗读、不进入主上下文。中文求助不触发，失败提供重试，切会话／新消息／取消时作废旧回包。开关说明每轮额外一次 AI 请求。
- 分层提示及优化结合上下文、场景双方角色、难度与词库候选；纠错优先最小必要修正，不强迫加入目标词。

## 第 5 批

- 工具栏“复盘”随时打开阅读面；点击生成才调用模型，不结束对话、不收藏任何条目。
- 每个会话保存一份最新复盘；仅新结果完整、引用校验通过且快照未过期时替换，失败／取消／过期保留旧版。
- 场景结束后可生成一份固定场景复盘，使用 `ScenarioEnding.messages` 冻结快照。固定文档不允许覆盖；稍后生成也不含续聊。最新复盘则包含点击时所有正式聊天，涵盖场景及续聊。提示、未发送练习录音均排除。
- 复盘使用中文讲解、英文参考，包含概述、场景／目标、可核对的对话依据、0–3 项表达改进和词汇搭配。引用必须来自快照；改进原句必须来自用户。仅据文字不推断发音、停顿、等级或分数。
- 长对话分为多个受限数据块，在一次请求中发送全部源消息。当前约束为序列化对话不超过 60,000 字符、单条不超过 18,000 字符、整次上下文不超过服务 70,000 字符预算。超限明确报错，保留原文档，不静默截断、不自动增加多次收费调用。此容量限制仍存在。
- 应用内阅读提供文本选择及 Markdown 导出，使用 Android 系统文件选择器，不需要广泛存储权限。导出文档 ID 在选择器期间可恢复；失败不影响本机文档。导出文件不会随后续最新复盘更新而回写。
- 场景首次结束转移持久化已展示标记，并只询问一次是否生成固定复盘。达成目标显示短暂勾选缩放反馈和完成卡；到限未达成只结束，不奖励、不计成功。重开、续聊、生成复盘都不重复计数。设置页显示成功总次数／不同场景数，场景选择项显示自身已完成次数。

## UI 与文案自检

- 沿用 Nunito、绿白消息和蓝色提示、75% 左抽屉、单行顶栏和独立设置页返回自动保存。没有底部导航，没有手动结束按钮。
- 工具栏保留“表达提示／话题语料／复盘”，低频的回退、手动收藏及练习录音放入更多菜单。复盘与重说使用可滚动全高任务面，短结束询问使用 AlertDialog。
- 删除消息操作里的重复说明、提示块每次出现的“仅供参考／点击收起／长按”等重复行、装饰性分类眉题；保留费用、字段、作用范围、错误和数据后果说明。
- 将原生可见文案中用 `·` 拼接的描述改为自然标点／字段关系，包括设置、场景角色／表单、词库预览、积累库和状态。许可正文和历史数据原文不改写。
- 对话页使用现有浅绿／浅蓝的低对比径向渐变，24 秒缓慢往返，仅绘制层更新。页面隐藏、后台、录音／回听或学习阅读面打开时静止；系统关闭动画时使用静态渐变。没有新增动画库、粒子或闪烁效果。
- [HTML 布局预览](../design/learning-recap-2026-10-31/index.html)及交付目录截图只解释布局和动效方向，不能证明 Android 实际布局／帧率。机械检测已修正预览的字号层级警告。

## 数据与异步保护

`learning.json` 数据版本为 4，配置版本为 3；旧字段保留，新字段默认关闭／空。录音、积累、词库、草稿与配对格式沿用。练习音频被正式消息引用后，回退清理检查全部会话、练习和场景冻结消息，避免删除共享音频。

纠错任务拥有独立代次／Job；主操作仍使用 GenerationSnapshot，正式消息变更继续使旧请求失效。场景判定仅核对正式对话和场景修订，避免纠错旁路导致判定失效；判定失败保留原结束状态。复盘另核对源消息摘要及被替换文档 ID。

本地写入继续使用 AtomicFile 及既有顺序持久化队列，失败保留内存内容并显示错误。不宣称设备磁盘故障、强杀瞬间或跨文件事务已实测；外部文件导出也仍需设备验证。

## 源码入口

- `data/LearningFeatures.kt`：分层有效性、独立练习、每次录音保留及显式发送。
- `data/Recaps.kt`：固定／最新快照、校验、不可覆盖规则与 JSON。
- `data/Models.kt`、`ConversationConfig.kt`、`ScenarioJson.kt`：兼容读写。
- `network/LearningFeatureProtocol.kt`：结构化提示词、双语／原句引用校验、Markdown 格式化。
- `network/AiClient.kt`：独立预算及完整返回检查。复用现有 Node 的 `learning`／`summary` 白名单，无需重启服务。
- `PracticeViewModel.kt`：生命周期、取消、请求编排、成功结算与首次结束反馈。
- `ui/LearningScreens.kt`、`ChatScreen.kt`、`SettingsScreen.kt`：练习、阅读／导出、渐变、奖励、统计及入口。
- `LearningFeaturesTest.kt`：25 项新回归，另导出 4 个合成生产请求和 Markdown 样本。
